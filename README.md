# СМП-76

Статический B2B-сайт светотехнической компании. Размещается на GitHub Pages с основным доменом **smp-76.ru**. Backend, сборщик, npm-зависимости приложения и внешние шрифты не нужны.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открывайте сайт через HTTP: каталог загружает локальный JSON. Публичные адреса страниц и `CNAME` сохранены. Для проектного пути GitHub Pages ссылки на `/` и `/#anchor` адаптируются в `js/site.js`, включая динамические хлебные крошки.

## Структура

| Область                                        | Файлы                                                             |
| ---------------------------------------------- | ----------------------------------------------------------------- |
| Главная, опыт, услуги, производители, контакты | `index.html`, `css/home.css`, `js/home.js`                        |
| Каталог и самостоятельная страница серии       | `catalog.html`, `series.html`, `css/catalog.css`, `js/catalog.js` |
| Технический подбор                             | `selection.html`, `css/selection.css`, `js/selection.js`          |
| Электроснабжение и галерея                     | `elektrosnabzhenie.html`, `css/electro.css`, `js/electro.js`      |
| Конфиденциальность                             | `privacy.html`, `css/privacy.css`                                 |
| Общая система, навигация и доступность         | `css/site.css`, `js/site.js`                                      |
| Декоративная сцена архитектурного света        | `js/light-scene.js`                                               |
| Полная техническая база                        | `catalog-data.json`                                               |
| Дополнительный исходный каталог                | `catalog.json`                                                    |

Фактическая техническая база в checkout называется `catalog-data.json`, содержит **174 серии / 18 226 модификаций** и имеет дату обновления 2026-07-16. Файла `SMP_catalog_final_2026-07-16.json` в исходном репозитории нет. Его предполагаемое содержимое не заменялось и не реконструировалось: используется существующая полная база, прошедшая все контрольные условия задания.

Поиск каталога индексирует полные данные однократно. В таблице модификаций выводится по 100 строк с переходом между страницами; поиск и сортировка работают по всей серии. Подбор сохраняет прежние критерии и допуск 15%, а исполнения создаются в DOM только при раскрытии. Сравниваются до трёх серий или конкретных артикулов. Для PLG выводятся текстовые placeholders, JSON и файлы изображений не изменены.

Hero использует исходную прозрачную фотографию FEREKS FHB и складской интерьер. Пятно света следует за курсором по всему hero; луч соединяет его с оптикой, а приглушённое фото доворачивается с инерцией. Фон виден только в освещённой зоне. Canvas/WebGL и автоматической пульсации нет. Без ввода и вне экрана обновления прекращаются; mobile, reduced motion и отсутствие JavaScript сохраняют статичную сцену. Это качественная демонстрация, не фотометрический расчёт. Подробности: [docs/HERO-FHB.md](docs/HERO-FHB.md).

## Проверки

Данные, SEO, локальные ссылки и CSS-ресурсы проверяются стандартной библиотекой Python:

```sh
python3 tests/data-and-pages.py
```

Сопоставление алгоритма подбора с исходным результатом до редизайна — 40 сценариев по всем моделям:

```sh
node tests/selection-regression.cjs
```

`tests/selection-baseline.json` содержит только условия, количества и контрольные хеши результатов, не копию каталога. Изменять базу и её контрольные хеши следует только в отдельной согласованной задаче обновления данных.

Для браузерных проверок нужны доступные в среде Playwright и Chromium. Они не подключаются к сайту и не требуются посетителю. В подготовленной облачной среде:

```sh
node tests/browser.cjs
node tests/presentation.cjs
```

Можно запустить отдельные группы: `layout home catalog comparison selection gallery fallback pages-path edge-cases`. Например:

```sh
node tests/browser.cjs catalog comparison
```

Сервер должен быть запущен. Переменные тестового процесса: `SMP_QA_BASE_URL`, `SMP_QA_CHROMIUM`, `SMP_QA_ARTIFACT_DIR`. По умолчанию результаты и снимки сохраняются вне checkout, в `/tmp/smp-lighting-qa`.

Сведения о решениях и проверках: [docs/REDESIGN.md](docs/REDESIGN.md).

Текущая creative direction, структура, motion system, токены и сохранность логики описаны в [docs/REDESIGN-V2.md](docs/REDESIGN-V2.md). Каталог поддерживает список и карточки; `js/presentation.js` и `css/engineering.css` отвечают за новую презентацию инженерных страниц.
