# CRI и цветовая температура: контроль окраски

Блок добавлен на главную перед существующим входом в технический подбор. Заголовок — «Как освещение влияет на контроль качества». Hero и остальные секции сохранены.

## Сцена и достоверность

Используется одна специально созданная иллюстрация автомобильного поста визуального контроля: синяя дверь, две красные кузовные панели с разными оттенками, серебристое крыло, отражения контрольных полос. Это сгенерированная промышленная визуализация, не фотография проекта SMP. Источник сохранён вне checkout; в сайт включён WebP 1586 × 992, около 184 КБ.

Во всех состояниях используются те же изображение и кадрирование. CRI 70/80/90/95 представлены условными матрицами цветопередачи с сохранением нейтральных тонов. В режиме температуры 3000/4000/5000/6500 K применяется условное изменение оттенка белого света. Матрицы не вычисляют CRI или спектр источника и не предсказывают внешний вид конкретного оборудования.

В интерфейсе есть подпись о наглядном характере иллюстрации. Отдельно поясняется, что видимость рельефных дефектов зависит также от направления света и отражений; CRI и цветовая температура не отождествляются.

## Взаимодействие

- Две доступные вкладки и нативные группы radio-переключателей.
- В каждом режиме сохраняется последнее выбранное значение.
- Мышь, касание, Tab, стрелки в группе radio; для вкладок — стрелки, Home и End.
- Обновляются значение, короткое объяснение, подпись сцены и подсказка, на что смотреть.
- Переход 480 мс между двумя слоями одного изображения. Старый слой остаётся непрозрачным под входящим, поэтому нет провала яркости.
- При быстрых переключениях очередь сохраняет только последнее требуемое состояние. Reduced motion применяет его сразу.
- Изображения загружаются лениво; canvas, WebGL, таймеров бесконечной анимации, зависимостей и сетевых сервисов нет.
- На мобильном сцена располагается над панелью управления; кнопки имеют высоту не менее 48 px и стоят в два ряда.

## Файлы

`index.html` содержит новый раздел и подключение двух локальных ресурсов. `css/colour-lab.css` полностью ограничен новыми классами. `js/colour-lab.js` читает только состояние образовательного блока. Каталог, подбор и JSON не используются и не модифицируются.

Автономный вариант для заказчика — [colour-lab-interactive.html](preview-v2/colour-lab-interactive.html). Сборка из действующей разметки, CSS и контроллера:

```sh
python3 scripts/build-colour-lab-preview.py
```

В автономном файле включены изображение, стили и скрипт. Его можно открыть после распаковки ZIP без HTTP-сервера. Полный сайт с каталогом запускается отдельно по [инструкции](../CLIENT-REVIEW.txt).

## Проверки

```sh
python3 tests/data-and-pages.py
node tests/colour-lab.cjs
node tests/presentation.cjs
node tests/browser.cjs layout home fallback pages-path
```

Проверяется загрузка сцены ниже первого экрана, все восемь состояний, видимые различия, одинаковый размер кадра, клавиатура, сохранение выбора, быстрые переключения, reduced motion и шесть ширин 375–1920 px. Также сравниваются контрольные суммы исходных файлов, hero и HTML за пределами вставки.

Снимки: [desktop](preview-v2/colour-lab-1440.jpg), [mobile](preview-v2/colour-lab-390.jpg). Это кадры интерфейса; для проверки движения используйте HTML или полный запуск.

Все перечисленные проверки пройдены. Axe-core 4.11.0 не обнаружил нарушений выбранных правил WCAG A/AA и 2.1 AA в обоих режимах при 1440 и 390 px. Контраст фотографии требует ручной оценки; автоматический результат не является полной сертификацией доступности. Автономный HTML проверен при отключённой сети на обеих ширинах.
