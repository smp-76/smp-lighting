# Hero: реальный FEREKS FHB

Ветка `redesign-preview-v2`. Изменение ограничено hero главной страницы, его стилями, контроллером и соответствующими проверками. Текущее уточнение выполнено поверх `bee3dfc`. HTML вне hero, остальные страницы, JSON, исходные изображения, SEO и sitemap сохранены.

## Источники и композиция

Основной ракурс — нижний 3/4: видны оптика, рёбра корпуса и поворотная лира. Переданный reference совпадает с имеющейся фотографией `images/fereks-fhb.webp`, уже с прозрачным фоном. Используется этот исходный файл без ретуши, перерисовки или изменения конструкции. Боковой и верхний reference использованы для проверки формы; переходов через выдуманные промежуточные ракурсы нет. Маленький preview не увеличивается.

Фон — существующее фото `images/reference-logistics.webp`. Это иллюстративная среда демонстрации, не утверждение о поставке FHB на изображённый объект. Постоянная видимость фотографии отключена: детали склада проявляются только внутри мягкой световой маски. За её пределами остаётся navy-фон. Лира и корпус остаются частью настоящего изображения светильника.

Слева в HTML размещены заданные владельцем H1, подзаголовок и две CTA. Справа — предметная сцена и ссылка на существующую `series.html?series=fereks-fhb`. На mobile текст и CTA стоят выше предметной сцены.

## Движение и свет

- Светильник поднят и уменьшен вдвое относительно `bee3dfc`: ширина изображения около 262 px при viewport 1440 и 154 px при viewport 390. Фото приглушено CSS-фильтром `brightness(.7)`; исходный файл сохранён.
- Контролируемый наклон плоскости: rotateX ±12°, rotateY ±20°, rotateZ ±6°; смещение до 12 px по горизонтали и 6 px по вертикали. Подпись остаётся неподвижной.
- Курсор управляет пятном по всему hero, включая область с текстом. Координаты маски и конца луча совпадают с местом наведения.
- Начало луча измеряется по точке на оптике внутри наклонённой фотографии. SVG-конус и градиент пересчитываются между этой точкой и пятном; свет не отрывается от светильника.
- Свет отвечает с постоянной времени 85 мс, фото доворачивается с инерцией 280 мс. При уходе курсора сцена мягко возвращается к исходной зоне освещения. Пульсации нет.
- После затухания движения, вне hero и в скрытой вкладке requestAnimationFrame прекращается. Прокрутка остаётся нативной.
- На mobile, при touch/coarse pointer, reduced motion, экономии трафика и без JavaScript — статичная освещённая зона. Текст, фотография и CTA остаются доступны.

Световая проекция качественная: реальная КСС, люксы и результаты светотехнического расчёта не имитируются. Плоскость PNG/WebP не вращается на 360°.

`js/light-scene.js` теперь содержит входной контроллер и отдельную функцию отображения состояния фотографии. Впоследствии её можно заменить адаптером настоящей GLTF/GLB-модели. 3D-зависимостей и модели в текущем изменении нет.

## Производительность

Canvas/WebGL удалены из hero. Контроллер — около 6 КБ исходного JS; изображение FHB — 55 350 байт, с заданными размерами и высоким приоритетом загрузки. Фон — существующий WebP 358 346 байт, повторно используемый в отраслевом блоке. Его загрузка имеет низкий приоритет. Текст не зависит от декодирования изображения или запуска контроллера. Новых библиотек, шрифтов и сетевых сервисов нет.

Полевые Core Web Vitals не измерены. Локальная проверка Chromium служит для проверки поведения и сдвигов макета, а не для обещания LCP на устройствах посетителей.

## Интерактивная проверка без сервера

JPG показывает только снимок. Для проверки движения подготовлен [автономный HTML](preview-v2/smp-hero-interactive.html).

Проще всего [скачать ZIP](https://raw.githubusercontent.com/smp-76/smp-lighting/redesign-preview-v2/docs/preview-v2/smp-hero-interactive.zip), распаковать его и открыть `smp-hero-interactive.html` двойным щелчком.

Если скачиваете отдельный HTML:

1. Откройте файл по ссылке и нажмите **Download raw file** (значок скачивания справа вверху на GitHub).
2. Откройте скачанный `smp-hero-interactive.html` в Chrome, Edge, Firefox или Safari.
3. На компьютере разверните окно шире 900 px и двигайте мышь по всему hero. Склад проявляется под курсором, светильник доворачивается к пятну, луч идёт от оптики к выбранному участку.

На мобильном экране и при reduced motion используется статичная сцена. Картинки, стили и контроллер включены в файл: после скачивания для просмотра не нужны сервер, интернет или установка зависимостей. Здесь показан только hero; ссылки открывают рабочий сайт в новой вкладке.

Файл собирается из текущих `index.html`, CSS и исходного контроллера, без отдельной реализации эффекта:

```sh
python3 scripts/build-hero-preview.py
```

Содержимое автономного файла проверено в Chromium при отключённой сети: изображения доступны, реакция на курсор работает, mobile и reduced motion статичны. На проверенном desktop-экране снимок совпадает с основной страницей пиксель в пиксель.

## Проверки

```sh
python3 tests/data-and-pages.py
node tests/browser.cjs layout home fallback pages-path
node tests/presentation.cjs
```

Проверки включают шесть ширин 375–1920 px, неподвижность без ввода, реакцию фото и света на курсор, совпадение пятна с курсором слева и справа, связь начала луча с оптикой, отсутствие постоянной видимости фона, ограничение угла, сохранение источника фото, прекращение обновлений вне экрана, mobile, reduced motion, отключённый JavaScript и отсутствие WebGL. Существующие сценарии отраслей, производителей и инженерного представления также проверяются.

Дополнительно сравниваются контрольные суммы всех файлов вне разрешённого набора и HTML главной за пределами hero. Проверка CSS ограничивает изменения правилами hero. `main` и production не обновляются.

Проверки пройдены. Axe-core 4.11.0 на главной при 1440 и 390 px: 0 нарушений выбранных правил WCAG A/AA и 2.1 AA; контраст фотографии требует ручной оценки. При локальной начальной загрузке Chromium накопленный сдвиг макета равен 0. Эти результаты не заменяют полную ручную проверку доступности или полевые Core Web Vitals.
