# Hero: реальный FEREKS FHB

Ветка `redesign-preview-v2`. Изменение ограничено hero главной страницы, его стилями, контроллером и соответствующими проверками. Основа — коммит `46ee871`. HTML вне hero, остальные страницы, JSON, исходные изображения, SEO и sitemap сохранены.

## Источники и композиция

Основной ракурс — нижний 3/4: видны оптика, рёбра корпуса и поворотная лира. Переданный reference совпадает с имеющейся фотографией `images/fereks-fhb.webp`, уже с прозрачным фоном. Используется этот исходный файл без ретуши, перерисовки или изменения конструкции. Боковой и верхний reference использованы для проверки формы; переходов через выдуманные промежуточные ракурсы нет. Маленький preview не увеличивается.

Фон — существующее фото `images/reference-logistics.webp`. Это иллюстративная среда демонстрации, не утверждение о поставке FHB на изображённый объект. Затемнённый общий слой сохраняет глубину стеллажей; маска освещённого слоя раскрывает детали поверхностей. Лира и корпус остаются частью настоящего изображения светильника.

Слева в HTML размещены заданные владельцем H1, подзаголовок и две CTA. Справа — предметная сцена и ссылка на существующую `series.html?series=fereks-fhb`. На mobile текст и CTA стоят выше предметной сцены.

## Движение и свет

- Ограничения плоскости фото: rotateX ±1,8°, rotateY ±2,8°, rotateZ ±0,8°; смещение до 6 px по горизонтали и 3 px по вертикали.
- Фото, мягкий конус, пятно света и маска видимых деталей используют одну ограниченную пару координат наведения. Свет не переключается и не пульсирует.
- Экспоненциальная инерция с постоянной времени 340 мс. После достижения цели requestAnimationFrame прекращается.
- Отрисовка останавливается вне hero и в скрытой вкладке. Нет обработчика wheel, изменения скорости прокрутки или обязательной scroll-анимации.
- При ширине до 900 px, touch/coarse pointer, reduced motion и экономии трафика используется статичная композиция. Без JavaScript фото, свет, текст и CTA остаются доступны.

Световая проекция качественная: реальная КСС, люксы и результаты светотехнического расчёта не имитируются. Плоскость PNG/WebP не вращается на 360°.

`js/light-scene.js` теперь содержит входной контроллер и отдельную функцию отображения состояния фотографии. Впоследствии её можно заменить адаптером настоящей GLTF/GLB-модели. 3D-зависимостей и модели в текущем изменении нет.

## Производительность

Canvas/WebGL удалены из hero. Контроллер — около 3 КБ исходного JS; изображение FHB — 55 350 байт, с заданными размерами и высоким приоритетом загрузки. Фон — существующий WebP 358 346 байт, повторно используемый в отраслевом блоке. Его загрузка имеет низкий приоритет. Текст не зависит от декодирования изображения или запуска контроллера. Новых библиотек, шрифтов и сетевых сервисов нет.

Полевые Core Web Vitals не измерены. Локальная проверка Chromium служит для проверки поведения и сдвигов макета, а не для обещания LCP на устройствах посетителей.

## Проверки

```sh
python3 tests/data-and-pages.py
node tests/browser.cjs layout home fallback pages-path
node tests/presentation.cjs
```

Проверки включают шесть ширин 375–1920 px, неподвижность без ввода, реакцию фото и света на курсор, ограничение угла, сохранение источника фото, прекращение обновлений вне экрана, mobile, reduced motion, отключённый JavaScript и отсутствие WebGL. Существующие сценарии отраслей, производителей и инженерного представления также проверяются.

Дополнительно сравниваются контрольные суммы всех файлов вне разрешённого набора и HTML главной за пределами hero. Проверка CSS ограничивает изменения правилами hero. `main` и production не обновляются.

Проверки пройдены. Axe-core 4.11.0 на главной при 1440 и 390 px: 0 нарушений выбранных правил WCAG A/AA и 2.1 AA; контраст фотографии требует ручной оценки. При локальной начальной загрузке Chromium накопленный сдвиг макета равен 0. Эти результаты не заменяют полную ручную проверку доступности или полевые Core Web Vitals.
