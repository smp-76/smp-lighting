# Редизайн и модернизация SMP-76

## Исходный аудит

В исходном проекте было шесть публичных страниц, встроенные CSS/JS, повторяющаяся двухуровневая навигация и фотографии в base64 внутри HTML. Каталог и `series.html` использовали расходящиеся версии скрипта. Обращение к отсутствующему `#purpose` останавливало инициализацию самостоятельной страницы серии. Поиск повторно собирал текст всех 18 226 моделей на каждом вводе. Таблица выводила первые 500 модификаций без продолжения; подбор ограничивал серии и заранее создавал строки скрытых исполнений.

Существующая бизнес-логика включает основную и дополнительные категории серии, фильтры производителя, категорий, мощности, оптики и IP, поиск по серии и артикулу, отдельные фильтры/сортировку модификаций, паспорт, копирование характеристик, сравнение серий. Технический подбор учитывает мощность, поток, IP не ниже заданного, группы оптики, CCT, минимальный CRI, монтаж и взрывозащиту. Близкие варианты имеют прежний допуск 15% по мощности/потоку. Маркировка «Нет» означает обычный светильник.

Сохранены фотографии и все девять отраслевых референс-листов, услуги, шесть этапов сопровождения проекта, пять производителей, контакты обоих направлений, электрофотогалерея и текст политики. Форм сбора заявок, аналитики, cookies, внешних шрифтов и внешних библиотек в приложении нет.

## Система оформления

Основа — синий действующего логотипа: `#006b95`, глубокая графитовая поверхность `#0a202a`, светлая бумага `#f5f6f3`, белый, спокойные технические разделители `#d5dfdf`. Латунный акцент используется для различий/близких результатов. Единые значения находятся в `css/site.css`.

- Системная кириллическая типографика; крупные заголовки с отрицательным трекингом; технические таблицы и табличные цифры.
- Шаг отступов 4 px, основные интервалы 8/12/16/24/32/48/64 px.
- Сдержанные радиусы 3 px, линии вместо декоративного стекла, тени только для интерактивных/всплывающих поверхностей.
- Основной контейнер 1440 px, расширение до 1560 px на больших экранах.
- Переходы 160/320 ms; появления до 600 ms ниже первого экрана. Первый экран не скрывается анимацией.
- Иерархия слоёв: header 50, dropdown 60, sheet 80, compare bar 90, modal 100, compare dialog 110, lightbox 120, уведомления 130.
- Адаптация оболочки при 1024 px, технических панелей при 900 px, мобильная композиция при 600 px. Проверяемые ширины: 375, 390, 768, 1024, 1440, 1920 px.

## Функциональные изменения

Каталог и страница серии используют один исходник. Добавлены CRI и CCT на уровне каталога; прежние фильтры сохранены. Полное состояние фильтров сохраняется в URL. Мобильная панель имеет явное применение, Escape, backdrop, возврат фокуса и замкнутый Tab-порядок. Поиск использует подготовленный текстовый индекс; ввод отложен на 120 ms.

Самостоятельная страница серии имеет доступную основную область, H1 и общую навигацию. В паспорте цветных модификаций CRI отображается как «Не применяется»; исходный null не подменяется. Таблица разбита на страницы по 100 строк; все модели доступны. Кнопки выбора артикула работают с клавиатуры. Копирование остаётся локальным действием.

Сравнение поддерживает прежние серии и конкретные артикулы. Добавлены удаление позиции непосредственно из таблицы, фиксированные заголовки и колонка характеристик, различия цветом, горизонтальная прокрутка, явное закрытие, Escape, backdrop и управление фокусом. Выбор из технического подбора передаётся в каталог через повторяющиеся параметры `compare`.

Подбор получил структуру «задача / требования / оборудование / сравнение». Восстановление IP и оптики из URL исправлено. Выбор цветного CCT сохраняется и фильтруется как цвет, а числовые критерии и допуски проходят регрессию с исходной реализацией. Результаты не теряются из-за прежнего ограничения числа карточек. Исполнения создаются порциями при раскрытии. Пустая выдача содержит параметры и прежний mailto-запрос.

Фотогалерея сохраняет стрелки, миниатюры, свайп и увеличение. Pointer capture включается только после начала горизонтального жеста, чтобы обычный клик открывал фотографию. Увеличение доступно через настоящую кнопку и клавиатуру.

## Данные, URL и SEO

`catalog-data.json`, `catalog.json`, CNAME, robots и файлы верификации поисковиков проверяются полными SHA-256-хешами. Контрольные условия: 18 226 моделей, ALF-\* = 0, null световой отдачи = 0, целая мощность; у 81 ARUNA SPOT S1R/2.5/ поток 210 лм. Существующие файлы изображений не переименованы и не удалены. Base64-фотографии вынесены в отдельные файлы без изменения их содержимого.

Все прежние URL сохранены. На внутренних страницах добавлены canonical, у подбора — description. Главная сохраняет canonical `https://smp-76.ru/`. Добавлены Organization JSON-LD и адрес страницы серий в sitemap; остальные записи и robots сохранены. Бизнес-контент, навигация и первый отраслевой референс доступны в HTML без WebGL/JavaScript.

## Проверка

Команды и группы тестов приведены в README. Браузерная проверка охватывает шесть страниц на шести ширинах; поиск, все группы фильтров и URL-восстановление; доступность всех модификаций; сравнение серий и артикулов; способы закрытия и удаление; подбор, пустую выдачу и навигацию; галерею; reduced motion, отсутствие WebGL и JavaScript; проектный путь GitHub Pages.

Проверка доступности выполнялась axe-core 4.11.0 по WCAG A/AA и WCAG 2.1 AA, с ручными сценариями клавиатуры и фокуса. Инструмент устанавливался только во временную папку проверки и не является зависимостью сайта.

Лабораторные измерения выполняются на локальном HTTP в Chromium без сетевого и CPU-ограничения. Это проверка реализации, а не полевые показатели посетителей. Реальные LCP/CLS/INP после размещения зависят от хостинга, сети и устройства; аналитика для их сбора в сайт не добавлялась. Нельзя переносить локальные цифры на production.

Изменения подготовлены в checkout. Публикация сайта и push в GitHub не выполнялись.
