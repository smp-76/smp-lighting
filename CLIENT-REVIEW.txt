СМП-76 — ВЕРСИЯ ДЛЯ СОГЛАСОВАНИЯ

1. Полностью распакуйте ZIP. Не запускайте файлы внутри окна архиватора.
2. Откройте review/START-HERE.html — там собраны демонстрации и снимки.

БЫСТРЫЙ ПРОСМОТР БЕЗ УСТАНОВКИ ПРОГРАММ

Hero со светильником: docs/preview-v2/smp-hero-interactive.html
Демонстрация CRI и температуры: docs/preview-v2/colour-lab-interactive.html
Эти два HTML работают после распаковки без сервера и интернета.
Для движения света в hero нужен компьютер с мышью и окно шире 900 px.
На мобильном hero статичен; переключатели CRI/CCT работают и на мобильном.

ПОЛНАЯ ВЕРСИЯ С КАТАЛОГОМ И ПОДБОРОМ

Windows: запустите START-SITE-WINDOWS.cmd.
macOS: запустите START-SITE-MAC.command.
Для запуска нужен установленный Python 3; дополнительные пакеты не требуются.
Браузер откроется автоматически. Оставьте окно запуска открытым на время просмотра.

Вручную, из папки распакованного сайта:
python3 review/serve.py
На Windows также можно: py -3 review/serve.py

Каталог и подбор загружают JSON, поэтому для полной проверки нужен HTTP-сервер.
Открытие index.html двойным щелчком не заменяет полный запуск сайта.

СТРАНИЦЫ ДЛЯ ПРОВЕРКИ

/ — главная, интерактивный hero, отрасли, новый блок CRI/CCT
/catalog.html — каталог, фильтры и сравнение
/selection.html — технический подбор
/series.html?series=fereks-fhb — пример серии и таблица модификаций
/elektrosnabzhenie.html — электроснабжение и галерея
/privacy.html — конфиденциальность

В архиве полный сайт: HTML, CSS, JavaScript, 174 серии / 18 226 моделей,
изображения, снимки, документация и исходные проверки. Node/npm для просмотра не нужны.
Статичная картинка не показывает интерактивность; используйте HTML-демонстрации или полный запуск.

Это версия ветки redesign-preview-v2 для согласования. Main и рабочий сайт не обновлены.
Сцена окраски — иллюстрация, не фотография проекта SMP и не точная симуляция спектра или CRI.
