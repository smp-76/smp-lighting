Версия сайта для согласования

Полный редизайн SMP: главная, каталог, технический подбор, страницы серий и электроснабжение. Пакет содержит все страницы, изображения и базу из 18 226 моделей.

Полностью распакуйте ZIP перед просмотром. Это отдельная версия для проверки; рабочий сайт не обновлён.

Интерактивные демонстрации

Работают без сервера и установки программ. Откройте HTML в обычном браузере.

Hero со светильником → CRI и цветовая температура →

В hero двигайте мышью по всему блоку: под курсором проявляется склад, луч идёт от оптики. Разверните окно компьютера шире 900 px. На мобильном hero статичен.

В сцене контроля окраски переключайте CRI и температуру. Это наглядная иллюстрация принципа, не точный светотехнический расчёт.

Полный сайт с работающим каталогом

Для полного просмотра нужен локальный HTTP-сервер: каталог и подбор загружают базу данных. Нужен установленный Python 3; дополнительные пакеты не требуются.

  • Windows: в корне распакованной папки запустите START-SITE-WINDOWS.cmd.
  • macOS: запустите START-SITE-MAC.command.
  • Вручную: из папки сайта выполните python3 review/serve.py (Windows: py -3 review/serve.py).

Браузер откроется автоматически. Оставьте окно запуска открытым во время просмотра.

При полном запуске проверьте главную, каталог, фильтры, сравнение, технический подбор, карточку серии и галерею электроснабжения. Двойной щелчок по основному index.html не заменяет запуск HTTP-сервера.
